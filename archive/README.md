# Preserved project history

Historical application code, retired providers/scripts, tests and dated
documents live here. Their contents retain their historical meaning; old
approvals and receipts do not authorize current provider calls.

`path_map.json` maps original tracked paths to their archived paths and records
the checksums verified during cleanup. Directory aliases at the original
historical import paths preserve old tests, links and readers. The current app
does not gain an active dependency on historical defenses or providers.

`docs_before_v3/` preserves the earlier report, README and demonstration plan.
Frozen datasets, saved experiment results, private settings and accounting stay
at their original locations. Local index rebuilds preserve ignored cache
generations in `local_evaluation_stores/`; explicit human-review imports preserve
before/decision/audit files in `evaluation_reviews/`.
