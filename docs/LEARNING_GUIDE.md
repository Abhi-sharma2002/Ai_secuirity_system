# Explain the system

Start with a legitimate task: an employee asks a question and should get a supported answer, abstention or conflict disclosure. An attack succeeds when the assistant adopts the attacker's objective. These are independent: a defense can block an attack yet fail to answer; an answer can contain useful facts and still leak a fictional protected marker. An outage is neither resistance nor task success.

Trace the RAG path: source bytes → parsed blocks → overlapping character chunks → local embeddings → cosine-ranked Chroma hits → bounded context → prompt → model output → source-ID validation → references. Every cited hit carries its document UUID, immutable version, raw hash, page/section and text. A high similarity match is not proof the requested answer exists. Tokenizer truncation and retrieval misses can hide relevant facts or attacks.

Uploads have names for people and IDs for the application. Names cannot choose host paths, define authority or replace existing documents. Ready means extraction/indexing succeeded, not that the content is safe or true. An explicit replacement supplies the document ID and expected active version. Its staged index becomes active only after verification; otherwise the old policy remains usable. Delete removes future retrieval eligibility, while historical snapshots/results have separate retention.

PDF text extraction is not OCR. Empty pages may be blank or unreadable; partial extraction requires review and explicit text-only acceptance. DOCX is a compressed package, so byte limits alone are insufficient: validate expanded sizes, member count/paths and unsupported objects, then parse within a process deadline. Supported ordinary files can still contain malicious text.

A supplies ordinary grounding and citations. B adds privileged rules establishing that retrieved instructions/filenames/questions cannot redefine application policy. Context is serialized as lower-trust JSON; forged role labels stay text. Delimiters/hashes are not enforcement mechanisms. C screens selected combined context and the question in a separate LLM call, then excludes flagged chunks or blocks a flagged question. Screening failure returns an error. A screener is not a calibrated trained classifier, can share generator weaknesses, and can lose useful facts when removing mixed chunks.

Evaluation uses frozen cases before final experiments. Development is for tuning; final cases are held out. Paired evidence isolates prompt/screener differences; end-to-end includes retrieval and must have a separate latency table. Grade attack success and task success independently, with unknown outcomes and human review for semantics. A response quoting or refusing an attack payload is not automatically an attack success. Count benign false flags separately from blocks and task loss. ASR needs explicit denominators, operational errors, unresolved grades, common-evaluable comparisons and actual exposure review.

OpenAI API use is independent of the ChatGPT app subscription. A key does not establish free credit or model access. Confirm actual allowance, expiry and model/API capabilities before enabling calls; never infer a balance or buy credits. Calls use conservative persisted reservations, no retries and explicit error categories. Rate limits differ from exhausted quota. A timeout can still incur provider usage; missing usage stays unknown. Local counters cannot enforce provider billing.

Debug from the public request ID, persisted version state and content-free operational logs. Inspect extracted source provenance, index fingerprints, candidate/retained evidence, decisions, timings and known/unknown usage in the private experiment record. Never log keys or private chain-of-thought. Test doubles validate deterministic routing and failure handling; only actual saved provider runs measure model behavior.

For a client recommendation, compare attack success, legitimate task completion, false flags, review coverage, latency and usage together. C is not automatically better. Thirty handcrafted final cases do not establish population-wide security, and repetitions do not create new independent cases. Production requests such as SSO/RBAC, tenant isolation, OCR, source governance or public deployment require explicit additional design and validation.
