# Demonstration procedure

The requested recorded attack demonstration is pending authorized live
evaluation. No video or successful baseline attack is claimed.

Local preparation can be demonstrated now: start the app with live answering
disabled, upload a fictional policy, search it in Local-only mode, and open the
current report. Its unavailable charts accurately show that live observations
are missing.

For the later recorded comparison, choose actual completed records showing a
successful baseline attack. Show a supported benign A answer, that actual A
attack result, the same case in B and C, a benign C answer, and the measured
trade-off charts. Show errors as errors and identify any unresolved reviews.
Use existing authorized records rather than resubmitting attacks for recording.
If no baseline attack succeeded, disclose that observation and select a real
comparison without inventing a successful attack.

Record the screen with the local recording tool, check playback and exclude
private settings, credentials and raw sensitive traces. Add the real video link
to README only after the recording exists. The historical demo plan is
preserved in `archive/docs_before_v3/DEMO.md`.
